# VCE Flour Alternatives v0.2.0

米粉・トウモロコシ粉は、かまど・電気コンロで各2種類の製粉指示を使えます。
x2：原料20個→粉20個、工数800。x8：原料80個→粉80個、工数3200。
既存の製粉指示は2倍量へ引き継ぎます。
VCE標準焼き料理7種の粉を、小麦粉・米粉・トウモロコシ粉のいずれか1種類で賄えます。
異種の粉は混合不可。同種の複数スタックは使用可。その他材料の混合仕様は元どおりです。

必要MOD：Harmony、Vanilla Expanded Framework、Vanilla Cooking Expanded（この順で当MODより上に配置）。
対象：RimWorld 1.6 / 1.7（各版のDLLを同梱）。

このフォルダをModsへ置き、当MODをVCEより後に有効化してください。
対象料理の粉の材料名は「穀物粉」と表示されます。

当MODの導入前からある製造指示では、米粉・トウモロコシ粉が未許可です。導入後に初めてセーブを読み込むと、小麦粉を許可している指示で両方を許可するかを1回だけ確認します。後から各指示の材料設定で変更することもできます。
導入後は小麦粉のチェックも有効になります。過去に小麦粉のチェックを外していた指示は小麦粉を使わなくなります。

v0.1.0はユーザーによるゲーム内検証の報告を受けて公開しました。v0.2.0の変更（製造指示の移行確認など）はゲーム内で未確認です。1.6/1.7のビルドと自動テストは確認済みです。
